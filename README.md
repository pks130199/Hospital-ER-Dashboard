# 🏥 Hospital Emergency Room (ER) Analytics Dashboard

## 📌 Executive Summary
This project delivers a comprehensive Power BI analytics solution designed to evaluate emergency room performance, track patient flow dynamics, and optimize healthcare operations. By analyzing key operational metrics across monthly and consolidated timelines, this dashboard empowers hospital administrators to monitor wait times, patient satisfaction, departmental referrals, and peak traffic periods.

---

## 🛠️ Tools & Technologies Used
* **Data Visualization & Dashboarding:** Power BI Desktop (DAX measures, interactive slicers, custom themes)
* **Data Processing & Analytics:** SQL / Excel
* **Documentation & Presentation:** Markdown & GitHub Portfolio
